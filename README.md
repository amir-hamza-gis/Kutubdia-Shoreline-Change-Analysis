# Shoreline Change Analysis of Kutubdia Island (2016–2025)

## Project Overview
This project analyzes shoreline changes of Kutubdia Island, Bangladesh, from 2016 to 2025 using satellite imagery, Geographic Information Systems (GIS), and Python.

The study focuses on identifying coastal erosion and accretion patterns and understanding the spatial distribution of shoreline changes.

## Study Area
Kutubdia Island, Cox's Bazar, Bangladesh.

## Data and Tools
- Landsat satellite imagery (2016, 2020, and 2025)
- ArcGIS / ArcMap
- Python
- Pandas
- NumPy
- ArcPy

## Methodology
1. Satellite image collection and preparation.
2. Image processing and MNDWI-based shoreline extraction.
3. Shoreline change analysis using transect-based methods.
4. Area-based erosion and accretion analysis.
5. Python-based calculations and geospatial data processing.
6. Map preparation and result visualization.

## Key Results
- Total eroded area: 153.40 hectares
- Total accreted area: 25.89 hectares
- Net land loss: 127.51 hectares
- Transects analyzed: 458
